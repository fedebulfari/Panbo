# Panbo Companion App

Welcome to the Panbo Companion App! 🎲

## About the Project

This project is a side companion application developed to be used alongside a custom board game designed by a friend. It is intended to enhance the tabletop experience, help manage game mechanics, and make playing the game smoother and more enjoyable.

## Live Version

You can access and use the fully functional web version of the companion app right from your browser. No installation is required!

👉 **[Access the Panbo Companion App Here](https://panbo.netlify.app/)**
